# ⚡ QuickSwap

> **QuickSwap** is a smart digital contact card & instant contact exchange web application. Share your profile, phone, WhatsApp, and social media handles seamlessly via dynamic QR codes or 1-click vCard (.vcf) download.

## 🚀 Features
- 📱 **Mobile-First Digital Card**: Clean, responsive, and glassmorphic UI.
- ⚡ **Real-Time Live Preview**: Instant visual updates as you type your details.
- 📥 **1-Click vCard (.vcf) Download**: Directly saves contacts into Android/iOS native phonebooks without installing any app.
- 📷 **Dynamic QR Code**: Generates scan-to-save QR codes on the fly.
- 💾 **Local Persistence**: Saves your card details in the browser using `localStorage`.

## 🛠️ Built With
- **HTML5 & CSS3**
- **Vanilla JavaScript** (DOM manipulation, Event Listeners, Blobs, Object State, LocalStorage)
- **QRCode.js**

## 💻 Getting Started
1. Clone the repository:
   ```bash
   git clone https://github.com/Priyanshu-kumar-maurya/quick-swap.git
   ```
